Crée, dans ce dossier vide, une application en ligne de commande en Python pour gérer les prêts de matériel d'une association. Le matériel a un nom et une quantité. Commandes : `python materiel.py ajouter NOM QUANTITE` ajoute du matériel (ou augmente sa quantité s'il existe déjà) ; `python materiel.py preter NOM PERSONNE DATE_RETOUR` prête un exemplaire à une personne, avec la date de retour prévue (AAAA-MM-JJ) ; `python materiel.py rendre NOM PERSONNE` enregistre le retour ; `python materiel.py stock` affiche chaque matériel avec le nombre d'exemplaires disponibles sur le total ; `python materiel.py retards DATE` liste les prêts dont la date de retour prévue est dépassée à cette date. Les données sont gardées dans `materiel.json`, à côté du programme. Une commande refusée affiche un message clair et se termine avec un code d'erreur. Ajoute les tests et un README qui explique comment installer et utiliser l'application.

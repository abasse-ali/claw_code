# Notes de version Claw Code 0.1.0 (brouillon)

## Résumé

Claw Code `0.1.0` est le premier jalon de préparation à la publication pour l'implémentation Rust actuelle. Claw Code est inspiré de Claude Code et construit comme une implémentation Rust en chambre blanche ; il ne s'agit pas d'un portage direct ni d'une copie. Cette version est centrée sur une expérience CLI locale utilisable : sessions interactives, prompts non interactifs, outils d'espace de travail, chargement de configuration, sessions, plugins, et découverte d'agents/skills locaux.

## Points forts

- Première version candidate publique `0.1.0` pour Claw Code
- Implémentation en Rust sûr comme surface produit principale actuelle
- CLI `claw` pour les workflows d'agent de codage interactifs et ponctuels
- Outils intégrés d'espace de travail pour le shell, les opérations sur fichiers, la recherche, la récupération/recherche web, le suivi des todos et les mises à jour de notebook
- Surface de commandes slash pour le statut, le compactage, l'inspection de config, les sessions, le diff/export et les informations de version
- Surfaces locales de découverte/gestion de plugins, agents et skills
- Connexion/déconnexion OAuth ainsi que sélection de modèle/fournisseur

## Installer et exécuter

Cette version est actuellement destinée aux builds depuis les sources :

```bash
cargo install --path crates/claw-cli --locked
# ou
cargo build --release -p claw-cli
```

Lancer :

```bash
claw
claw prompt "résume ce dépôt"
```

## Limitations connues

- Distribution par construction depuis les sources uniquement ; les artefacts de release empaquetés ne sont pas encore publiés
- La CI couvre actuellement les builds, vérifications et tests release sous Ubuntu et macOS
- La maturité des releases sous Windows n'est pas encore établie
- Certaines couvertures d'intégration sont en opt-in car les identifiants de fournisseur en direct et un accès réseau sont requis
- Les interfaces publiques peuvent continuer d'évoluer pendant la ligne de versions `0.x`

## Cadrage de release recommandé

Positionner `0.1.0` comme la première version publique de Claw Code dans son implémentation Rust actuelle, destinée aux adopteurs précoces à l'aise avec la construction depuis les sources. La surface fonctionnelle est suffisamment large pour un usage réel, tandis que l'empaquetage et l'automatisation des releases pourront continuer à s'améliorer dans les versions ultérieures.

## Vérifications utilisées pour ce brouillon

- Version de l'espace de travail vérifiée depuis `Cargo.toml`
- Chemin binaire/paquet `claw` vérifié depuis `cargo metadata`
- Surface des commandes CLI vérifiée depuis `cargo run --quiet --bin claw -- --help`
- Couverture CI vérifiée depuis `.github/workflows/ci.yml`
